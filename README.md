# 180 Studio API

Backend repository for the 180 Studio Architecture Portfolio rebuild.

## Purpose

This repository will contain the NestJS API for public portfolio data and the protected admin CMS. It is a learning project focused on modular backend design, PostgreSQL data modeling, transactions, secure cookie authentication, media uploads, and testing.
